# Web UI

This repo now includes a real React/Vite frontend prototype in `src/`.

## Run the frontend

```
npm install
npm run dev
```

Open the local URL shown by Vite.

The original Python/SQLite prototype remains in the repository while the web frontend is migrated screen by screen. The dashboard is fully redesigned; the remaining navigation screens currently use frontend placeholders and still need API wiring before they replace the Streamlit workflow.
